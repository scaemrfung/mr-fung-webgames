    How to play

    1. Start with the first word.
    2. Change one letter to make a new, real word.
    3. Keep going until you reach the target word.
    4. Stuck? Tap Hint — it shows you a good next step.
    C A T

    CAT → HAT → HAM. Only one letter changes each time — and HAT and HAM are both real words.

    Grown-up tip

    Say each new word out loud. Ask: “Does it sound like a real word? Which letter changed?” The gold letter shows the change.

    Keyboard

    You can also type letters on a real keyboard. Press Enter to check, and the arrow keys to move between letters.
